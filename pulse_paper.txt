Longitudinal alignments and syntheses of 
multimodal clinical data for personalized 
medicine with the PULSE framework
 
Multimodal models capable of imputing diverse data used in single-cell 
biology studies provide potential foundational opportunities in clinical 
practice. However, patient data uniquely comprise longitudinal mosaic 
measurements that reflect underlying physiological dynamics and 
exhibit temporal covariation, demanding a specialized approach. Here we 
present Patient Unified Longitudinal Signal Engine (PULSE), a longitudinal 
self-supervised framework that explicitly encodes personalized past states 
(historical paired modalities) to reconstruct full profiles from subsequent 
unpaired measurements, thus enhancing current visit multimodal 
alignment and generation. Applied to the UK Biobank, PULSE accurately 
generates metabolomic profiles and proteomic profiles from sparse 
routine blood tests. Compared with the ground truth metabolomic data 
(251 biomarkers), PULSE-generated profiles outperformed all benchmark 
methods. Furthermore, the framework accommodates incorporation of 
retinal images, electronic health records and blood markers with disease 
prediction: models trained on the generated proteomic profiles achieved 
areas under the curve of 0.72–0.83 for six common diseases, comparable 
to that using ground-truth proteomic data. The PULSE framework 
demonstrates that cross-modal alignment captures the continuous 
spectrum of disease physiology and extracts robust features that transcend 
the limitations of traditional binary case–controls.
Precision medicine leverages high-resolution, multimodal meas-
urements to capture human physiological complexity1–5. Deep phe-
notyping, such as high-throughput proteomics and metabolomics, 
provides rich functional signatures and when collected longitudinally, 
reveals within-individual changes invisible in cross-sectional 
data6–9, while large-scale efforts such as the UK Biobank demonstrate 
the value of dense profiling10. However, the cost and operational 
complexity of repeated deep multimodal profiling limit its use in 
routine care11, limiting access to well-resourced research settings12,13. 
Most healthcare systems therefore still rely on sparse laboratory 
measurements that capture only fragments of an individual’s 
physiological state.
Single-cell multimodal methods offer a conceptual starting point: 
distinct modalities (transcriptome, chromatin accessibility and surface 
proteins) are treated as complementary views of a shared biological 
state. By leveraging this principle, methods such as MultiVI14, scVAEIT15 
and MIDAS16 establish that distinct modalities measured on the same 
biological entity can be strongly coupled through a shared latent state 
and can be used to reconstruct one another. However, these methods 
are typically suited to snapshot observations because each cell usually 
can be measured once. Clinical data differ fundamentally: the same 
individual is measured repeatedly, creating longitudinal multimodal 
data where information lies both within visits (cross-modal depend-
encies) and across visits (temporal covariation). A test result is more

During training, we applied an active modality masking strategy 
to encourage true cross-visit and cross-modal inference. Randomly 
selected observed modalities were masked from the encoder inputs but 
retained as reconstruction targets, forcing the model to reconstruct 
them from the remaining modalities and the patient-specific historical 
context encoded in the Past-State. Reconstruction losses were applied 
wherever ground truth was available, while adversarial objectives 
reduced artifacts arising from missingness patterns. The Visit-State 
was then propagated through a temporal module, implemented in 
either recurrent neural network (RNN)-like or transformer-like form, 
to generate the Past-State for visit N + 1 and model patient trajec-
tories as individualized physiological state transitions rather than 
disconnected snapshots.
Benchmarking PULSE against state-of-the-art  
multimodality methods
We benchmarked PULSE using ~10,000 UK Biobank participants who 
had paired measurements from one baseline visit and one follow-up 
visit across two modalities: 61 routine laboratory tests and 251 metabo-
lomics biomarkers (Supplementary Table 1). Individuals were randomly 
assigned at the patient level to a training set (70%, n = 7,000) and a 
held-out test set (30%, n = 3,000), such that all visits from each test indi-
vidual were completely excluded from model training. To ensure a fair 
comparison, all methods were evaluated under the same patient-level 
train/test split and on the same reconstruction target. The evaluation 
task was to reconstruct Follow-up Visit metabolomics from Follow-up 
Visit laboratory tests. For PULSE, the same individual’s baseline visit full 
multimodal profile was additionally used to provide historical context, 
consistent with the intended longitudinal use of the framework.
As baselines, we adapted three representative single-cell mul-
timodal methods spanning distinct integration paradigms (see the 
‘Adaptation of single-cell multimodal frameworks’ section in the 
Methods for a description of the adaptation procedures): MIDAS, 
based on variational inference with a PoE architecture16,25; scVAEIT, 
which uses a probabilistic variational autoencoder to learn a joint 
latent space14,15; and StabMap, which performs cross-modality align-
ment through mutual nearest neighbors26,27. Notably, we treated 
them as adapted static multimodal frameworks: each visit from 
training-set individuals was treated as an independent paired sample, 
and the models were trained without access to historical-state variables. 
In the test, all static frameworks received only follow-up visit laboratory 
tests as input and were evaluated on reconstruction of the correspond-
ing Follow-up Visit metabolomics, thereby matching the reconstruc-
tion target used for PULSE. All formal benchmark comparisons were 
performed across the complete, unfiltered panel of 251 metabolites. 
For each metabolite and each method, we computed Pearson’s r, mean 
absolute error (MAE) and mean squared error (MSE) between predicted 
and measured values in the held-out test set. Under this evaluation, 
PULSE consistently outperformed all benchmark methods across all 
three metrics (Fig. 2a and Supplementary Table 2; P < 0.001).
We next examined which metabolites were reconstructed most 
faithfully by PULSE. To provide a feature-level view, we highlighted 
the ten metabolites with the highest Pearson correlations between 
predicted and measured values in the full PULSE model (Fig. 2b). Nota-
bly, many of the top-ranked features were lipid ratio markers, which 
are physiologically important and often thought to reflect relatively 
stable aspects of metabolic regulation. This observation prompted us 
to ask whether differences in metabolite predictability might be related 
to their longitudinal stability. Motivated by recent studies suggesting 
that many blood markers fluctuate around stable, patient-specific set 
points rather than a single population average28,29, we investigated 
whether variation in imputation performance could be explained by 
intra-individual stability. Specifically, for each metabolite, we quan-
tified intra-individual stability by computing the Spearman corre-

clinical data requires explicit modeling of cross-visit temporal context.
Longitudinal clinical modeling has advanced rapidly, yet most 
applies general sequence architectures (recurrent networks and trans-
formers) to single-modality measurements, such as laboratory values 
or clinical events recorded over time18,19. Multimodal extensions typi-
cally rely on input-level concatenation or parallel encoding with late 
fusion3,20. Representation learning often depends on diagnostic labels 
or case–control outcomes6,21,22. However, physiology evolves along a 
continuous spectrum; discrete labels incompletely capture underlying 
states and may inherit label bias23. Existing approaches therefore fail to 
model cross-visit and cross-modal relationships or to handle realistic 
missingness and missing-modality imputation24.
We propose that individuals should be modeled as dynamic sys-
tems where modalities are temporally covarying, complementary 
observations of an evolving latent physiological state. Under this view, 
changes in one modality constrain plausible trajectories in others, and 
prior states enhance missing-modality imputation. We formalized this 
as the Patient Unified Longitudinal Signal Engine (PULSE), which learns 
patient-specific temporal context to improve current-visit imputation. 
We demonstrate PULSE across diverse settings: metabolomic imputa-
tion from routine blood tests in the UK Biobank; proteomic generation 
from laboratory tests plus medical history; 30-day intensive care unit 
(ICU) readmission prediction jointly modeling laboratory data and clini-
cal text across US and Chinese cohorts; and enhanced cross-body dis-
ease prediction through alignment of retinal imaging with blood tests.
Results
The PULSE framework
To model longitudinal multimodal clinical data with incomplete obser-
vations, we developed PULSE (Fig. 1a,b). PULSE is based on the premise 
that different clinical modalities are biologically coupled, temporally 
covarying readouts of an individual’s evolving physiological state, 
rather than independent targets for direct translation. As patients 
differ in their baseline physiology and prior trajectory, the same 
measurement at a given visit may correspond to different underlying 
states. Thus, the physiologically informative signal lies not only in 
the absolute value observed at the current visit but in its change from 
the patient’s prior state, which in turn constrains plausible changes in 
other modalities.
PULSE operationalizes these principles by explicitly carrying 
forward an individualized latent summary of the previous visit, termed 
the Past-State, and using it as context for modeling the current visit. At 
visit N, PULSE encodes each observed modality into a modality-specific 
latent representation, while a dedicated Past-State branch summarizes 
patient-specific historical physiology from visit N − 1. These represen-
tations are mapped into a shared latent space through soft distribu-
tional alignment, which promotes physiological consistency across 
modalities and across time without forcing them into an identical code. 
This encourages PULSE to capture cross-visit shared information that 
reflects an individual-specific physiological state, while still allowing 
temporal variation around that state. The aligned signals are integrated 
into a unified Visit-State, which is decoded to reconstruct all modalities 
at the current visit, including those not observed, thereby enabling 
cross-modal imputation and placing incompletely observed visits in 
the same physiological space as fully observed visits. This reconstruc-
tion supervisory anchor ensures that the current-modality latent states 
remain faithful to the present observations, while the historical state 
serves only as supportive context for the current state rather than a 
template that the current data must follow. We also show theoretically 
that conditioning on the Past-State yields a more informative and 
tighter posterior over the current latent state, thereby reducing the 
posterior reconstructive variance for missing modalities (Supple-
mentary Note 1).

longitudinal multimodal measurements with missing modalities at different 
visits (left, crossed-out icons). Modalities are treated as temporally covarying 
readouts of an evolving physiological state; the framework uses this structure to 
infer or impute a complete multimodal description at each visit (right).  
b, Architecture of the PULSE framework. Encoders integrate the latent ‘Past-State’ 
from previous visits with current sparse ‘Measured Data’ across modalities to 
derive a unified ‘Visit State’. The Past-State vector produced at the previous visit 
is not reused verbatim: it is passed through a dedicated Past-State encoder at the 
current visit to obtain a historical-context latent branch that is aligned and fused 
with the current-visit branches into a unified Visit-State. Decoders use this joint 
latent representation to generate complete modalities. A recurrent mechanism 
propagates the latent state from the previous visit (for instance, Visit-N State) to 
serve as the Past-State input for the subsequent visit (for instance, Visit-N + 1).

To explore the clinical importance of this heterogeneity, we strati-
fied participants into three trajectory groups on the basis of their rela-
tive UMAP2 positions within narrow age strata (for instance, grouping

age-matched peers in other groups. Consequently, we interpret this 
specific branch as representing an accelerated-aging trajectory.
Leveraging clinical context to generate actionable molecular 
profiles for disease prediction
Although our core framework leverages a patient’s prior multiom-
ics state as context, such data are rarely available in routine care. By 
contrast, medical history, encompassing diagnoses, medications and 
comorbidities, is routinely recorded and provides a rich longitudinal 
summary of a patient’s physiological trajectory. Therefore, we hypoth-
esized that this easily accessible clinical context could serve as a power-
ful surrogate to guide the generation of expensive molecular profiles, 
such as plasma proteomics, from inexpensive routine laboratory tests 
(Fig. 4a). To test this, we applied PULSE to the UK Biobank-PPP cohort 
(n = 50,000; Supplementary Table 1), which includes paired proteomic 
(2,923 features), laboratory test (61 features) and medical history data. 
We split the cohort at the patient level into a 70% development set for 
training and a 30% held-out test set for evaluation. The task was to 
generate proteomics profiles of a visit using laboratory tests from that 
visit, combined with the encoded medical history context.
We benchmarked the PULSE model against three adapted 
single-cell methods (MIDAS, scVAEIT and StabMap) and PULSE abla-
tions. The PULSE model was trained on the development set using 
paired routine laboratory tests, encoded medical history and meas-
ured proteomics and evaluated on the held-out test set by generating 
proteomics from laboratory tests and medical history. The single-cell 
baseline methods were trained on paired laboratory tests and proteom-
ics in the training set but evaluated using laboratory tests only (without 
medical history). Performance was quantified using Pearson’s correla-
tion (r) between generated and measured protein abundance for each 
protein in the held-out test set. For direct comparison, we plotted each 
method’s per-protein r against that of the full PULSE model (Fig. 4b); 
nearly all points fell below the diagonal (y = x), indicating that PULSE 
outperformed the benchmarks for the majority of proteins. We addi-
tionally computed Spearman rank correlations between generated 
and measured levels as more robust analysis; the same pattern held, 
with nearly all points below the diagonal (Supplementary Fig. 5). We 
further examined performance on a clinically important subset of 15 
pleiotropic proteins (Fig. 4c). For these proteins, the full PULSE model 
also achieved a high Pearson’s r and outperformed all other baselines.
We further benchmarked PULSE against established approaches 
for learning patient trajectories from large-scale electronic health 
record data on the proteomics generation task. We considered three 
representative paradigms: (1) Delphi18, a transformer-based model for 
longitudinal diagnosis-event trajectories that does not incorporate 
routine laboratory tests as inputs, adapted here to predict proteomics 
directly from its trajectory representation; (2) adapted general large 
language model (LLM) (Llama 3.1)20, by converting medical history 
and routine laboratory tests into natural-language prompts for a gen-
eral LLM, from which we derived text embeddings for downstream 
proteomics prediction; and (3) a standard Transformer encoder that 
tokenizes disease codes and laboratory values for direct sequence 
modeling, trained end-to-end to predict proteomics. PULSE signifi-
cantly outperformed all three baselines in proteomics generation 
accuracy, yielding a clear overall ranking (PULSE > Transformer > Llama 
3.1 > Delphi; Supplementary Fig. 6). Delphi’s weaker performance

To assess the clinical utility of generated versus measured prot-
eomic profiles for disease prediction, we evaluated both in six major 
age-related diseases. On the development cohort (Methods), we 
trained Light Gradient Boosting Machine (LightGBM) models—a 
standard choice for proteomics-based prediction—using measured 
proteomics with age and sex as the reference inputs and evaluated 
predictions on the held-out test cohort. We then repeated training 
and evaluation using PULSE-generated proteomics (with age and sex) 
and directly compared performance with the measured-proteomics 
models. The area under the receiver operating characteristic curve 
(AUROC) was comparable between generated and measured inputs 
across all six diseases (Fig. 4d). As the area under the precision–recall 
curve (AUPRC) is often more informative under class imbalance, we 
additionally reported AUPRC and included an age-and-sex-only Light-
GBM baseline. Models trained on generated proteomics achieved 
a AUPRC comparable to measured proteomics across diseases, 
with both substantially outperforming the demographic baseline 
(Supplementary Fig. 7). Individual risk scores were also tightly aligned 
between the two settings (Supplementary Fig. 8a), indicating that 
generation preserves biological signal sufficient for risk stratification. 
We also performed a test on the remaining UK Biobank participants 
(n = 400,000) without measured proteomics. A model using labora-
tory tests, medical history and PULSE-generated proteomics signifi-
cantly outperformed a model using only the original laboratory tests 
and medical history (Supplementary Fig. 8b). This result suggests 
that the generative process is a potent representational optimizer. 
It effectively distills information from the sparse, heterogeneous 
clinical inputs into a structured and biologically richer proteomic 
feature space.
To further test whether comparable accuracy between gener-
ated and measured proteomics reflected genuine biology rather than 
statistical artifacts, we performed Shapley Additive Explanations 
(SHAP)-based interpretability on LightGBM models trained separately 
on each input type and compared the top important protein. Across 
diseases, the most influential proteins were highly concordant between 
the two input settings (Supplementary Fig. 9), supporting that gener-
ated proteomics preserves clinically meaningful structure and matches 
measured proteomics not only at the level of global performance 
metrics but also at the level of feature-level explanations.
Multicenter validation of PULSE for heterogeneous 
longitudinal multimodal modeling
To further demonstrate that PULSE can flexibly adapt to varied clini-
cal settings with heterogeneous longitudinal multimodal data, and 
to evaluate its advantage over representative longitudinal clinical 
modeling baselines, we applied the framework to two distinct ICU 
cohorts: the US-based MIMIC-III cohort, comprising 44,265 adult 
patients (≥18 years old) with 3,025 cases of 30-day ICU readmission, 
and a China-based large-scale ICU dataset (the Wenzhou ICU cohort), 
which included 13,816 adult patients (≥18 years old) with 793 cases of 
30-day ICU readmission. We focused on predicting 30-day readmis-
sion among ICU patients, a complex task requiring the integration 
of structured laboratories and unstructured clinical notes (see the 
‘Multicenter 30-day readmission among ICU patients’ section in the 
Methods). We compared PULSE with three representative longitu-
dinal clinical data modeling strategies: (1) a Transformer using the 
laboratory-test modality only for patient representation, modeling 
repeated structured variables over time; (2) a general LLM using the 
text modality only, where all note text within the observation window 
was encoded by Llama 3 to obtain a patient representation; and (3) a 
late-fusion model (Directly Combined) that learned separate encoders 
for structured trajectories and text embeddings and combined the two 
representations at prediction.
We evaluated all methods on 30-day postdischarge readmission, 
using only data from the first 48 h after the first ICU intime. For PULSE, 
this window was divided into 4-h steps. Structured measurements were 
summarized at each step, and contemporaneous clinical notes were 
aggregated into step-level text inputs, encoded by Llama 3 and aligned 
with structured features at each step while propagating patient-level 
temporal context across steps. All baselines were trained and evaluated 
under the same input scope, time window, prediction task and train/
validation/test splits within each cohort.
In the MIMIC-III cohort, PULSE achieved an AUROC of 0.713 (95% 
confidence interval (CI) 0.691–0.732) and an AUPRC of 0.193 (0.167–
0.224) (Supplementary Fig. 10), outperforming Directly Combined 
(0.663; 0.130), LLM (clinical notes) (0.647; 0.127) and Transformer 
(laboratory test) (0.639; 0.110). Similarly, in the Wenzhou ICU cohort, 
PULSE achieved an AUROC of 0.735 (0.683–0.789) and an AUPRC of 
0.388 (0.298–0.480), outperforming Directly Combined (0.706; 0.317), 
LLM (clinical notes) (0.691; 0.273) and Transformer (laboratory test) 
(0.647; 0.116). These results support the flexible use of PULSE in acute 
care and its consistent gains over representative longitudinal baselines 
on structured- and text-based multimodal ICU trajectories across two 
healthcare systems.
Multimodal alignment enhances single-modality 
representation
We extended PULSE to more heterogeneous modalities, retinal fundus 
images and laboratory tests, to test whether longitudinal multimodal 
alignment could enhance the predictive power inherent to each indi-
vidual modality. We hypothesized that, through cross-modal pretrain-
ing, PULSE would learn to encode systemic health information within 
fundus image features and, conversely, capture ocular-relevant signals 
from laboratory tests. To validate this, we designed a rigorous test of 
cross-body prediction task: forecasting pediatric myopia progression 
from laboratory tests and predicting systemic disease from retinal 
fundus images.
For the myopia progression prediction task, we used a longitudinal 
cohort of 24,605 children (50,043 visits; Supplementary Table 1) where 
each participant contributed at least one visit with laboratory tests and 
one visit with fundus images, although individual visits may contain lab-
oratory tests only (19.4% of visits), fundus images only (15.0%) or both 
modalities (65.6%). The dataset was randomly partitioned by individual 
in a 7:3 ratio for development and held-out test sets. We first pretrained 
PULSE on the development set to align fundus-derived features with 
laboratory tests across visits. The PULSE latent representation was then 
fine-tuned, using only laboratory test inputs, to predict future axial 
length (AL) and spherical equivalent (SE) trajectories over 1–5-year 
horizons. Against an end-to-end baseline (see the ‘Baseline methods 
of multimodal alignment’ section in the Methods) trained solely on 
laboratory tests, the PULSE pretrain–fine-tune strategy consistently 
achieved stronger predictive capacity for both AL and SE at every 
horizon (Fig. 5a–c and Supplementary Fig. 11), demonstrating that 
cross-modal pretraining distills ocular-relevant structure into labora-
tory representations that improves longitudinal vision forecasting.

Discussion
PULSE differs from existing longitudinal clinical modeling approaches 
in its core objective. Most prior methods apply general sequence 
architectures (RNNs and transformers) to clinical trajectories, typi-
cally focusing on a single modality. Multimodal extensions usually rely 
on input-level concatenation or late fusion of independently encoded 
representations, with representation learning driven by diagnostic 
labels. These approaches inadequately model how modalities biologi-
cally couple and covary as physiological states evolve. By contrast, 
PULSE explicitly aligns information across visits and modalities in 
a shared latent space, allowing modalities to provide mutual super-
visory constraints. By jointly leveraging longitudinal context and 
cross-modal covariation, PULSE improves robustness under realis-
tic missingness and supports reliable inference in heterogeneous 
clinical data.
A further future direction is the development of patient-specific 
longitudinal models. Although PULSE currently learns shared temporal 
and cross-modal structure at the population level, its design also sug-
gests a natural path toward more individualized modeling. In particular, 
once longitudinal data become sufficiently dense within each patient, 
for example, with more follow-up visits, richer multimodal coverage 
and longer observation windows, it may become possible to train or 
fine-tune patient-specific models that more precisely capture unique 
physiological trajectories. Such extensions could allow the model to 
distinguish stable personal baselines from individual-specific rates and 
directions of change. Future work may therefore explore patient-level 
adaptation strategies built on PULSE, including patient-specific 
fine-tuning or hierarchical formulations that combine shared popu-
lation structure with personalized trajectory modeling.
The PULSE framework carries potential to alleviate healthcare 
burdens and advance health equity32. By generating actionable molecu-
lar profiles from inexpensive, routine data, it democratizes access 
to advanced phenotyping, which is typically confined to large-scale 
research biobanks. This capability is particularly impactful for 
resource-limited settings, where dense multiomics profiling is pro-
hibitively costly. Remarkably, the generated proteomic profiles achieve 
predictive accuracy comparable to ground-truth measurements. In 
some instances, models using generated data even outperformed those 
using original inputs, suggesting that the generative process acts as a 
powerful representational optimizer, distilling and refining biological 
signals from sparse clinical data33. Consequently, this cost-effective 
strategy can help mitigate health disparities and integrate precision 
medicine tools into routine clinical care34.
PULSE is intended as a general framework rather than a univer-
sal model. Its value lies in providing a principled, flexible approach 
to develop task-specific models across modality combinations and 
clinical settings. Two limitations should be acknowledged. First, the 
specific models developed here should not be assumed to generalize 
across all populations; robustness across demographic subgroups 
and healthcare systems remains to be established. Second, PULSE 
should be viewed as a proof-of-concept framework requiring rigorous 
task-specific evaluation and prospective clinical validation before 
broad deployment.

Adaptation of single-cell multimodal frameworks
The clinical dataset consists of measurements from 10,000 UK 
Biobank participants, involving 61 routine laboratory tests (modal-
ity A) and 251 metabolomics biomarkers (modality B). To prepare 
the data for single-cell multimodal frameworks, which are typi-
cally designed for count-based genomic data, we first performed 
log-transformation followed by Z-score normalization on all continu-
ous clinical variables to ensure they are on a comparable scale. The 
dataset was split at the patient level into a training set (70%, n = 7,000) 
and a test set (30%, n = 3,000). For the single-cell frameworks, each 
visit (Baseline and Follow-up) from the training participants was 
treated as an independent paired sample (A and B), effectively con-
verting the longitudinal data into a static dataset of 14,000 paired 
observations for training.
We adapted three representative single-cell frameworks to handle 
continuous clinical data and perform cross-modality imputation:
(1)	 MIDAS adaptation: MIDAS is a deep probabilistic framework 
based on a product-of-experts (PoE) architecture. We adapted 
the input and output layers of MIDAS to handle continuous 
feature blocks instead of discrete counts. The negative bino-
mial likelihood typically used for single-cell data was replaced 
with a Gaussian likelihood to model clinical biomarkers. The 
framework uses modality-specific encoders to map labora-
tory tests and metabolomics into a shared latent space. The 
PoE mechanism allows the model to generate a joint poste-
rior distribution even when one modality is missing during 
inference.
(2)	 scVAEIT adaptation: scVAEIT uses a variational autoencoder 
with a missing mask mechanism. We adapted this by concat-
enating the laboratory tests and metabolomics into a single 
vector. We configured the model to use a continuous Gaussian 
distribution for the reconstruction loss. The core adaptation 
involves the masking strategy: during training, the model 
learns the conditional distribution of metabolomics given 
laboratory tests by randomly masking features and minimiz-
ing the reconstruction error of the unobserved variables.
(3)	 StabMap adaptation: StabMap is a nongenerative approach 
that uses mosaic data topology and mutual-nearest-neighbor 
(MNN) alignment. We designated the paired training data as 
the reference dataset. The 61 laboratory tests served as the 
shared features between the training reference and the test 
query. StabMap builds a topology where the test samples are 
projected onto the reference coordinates by traversing the 
shortest path defined by the shared laboratory features, ena-
bling the imputation of the unshared metabolomics features 
on the basis of the reference distribution.
For the training procedure, all three adapted frameworks were 
trained using the 7,000 training-set individuals. Each visit was treated 
as an independent sample, and the models were trained without access 
to any temporal or historical state variables. For MIDAS and scVAEIT, 
training involved optimizing the evidence lower bound (ELBO), which 
includes the reconstruction accuracy of both the laboratory tests 
and the metabolomics biomarkers alongside a regularization term 
for the latent space. StabMap was trained by establishing the ref-
erence coordinate system and embedding the training data into a 
stabilized mosaic space. No information from the test set was seen 
during this phase.
For testing and evaluation, at the test time, the evaluation was 
standardized to match the target task of reconstructing Follow-up 
Visit metabolomics from Follow-up Visit laboratory tests. For each 
held-out patient in the test set (n = 3,000), only the laboratory tests 
from their second visit were provided as input to the models. MIDAS 
and scVAEIT performed inference by passing the laboratory tests 
through their trained encoders and using the resulting latent rep-
resentations to decode/impute the missing metabolomics. Stab-
Map projected the test laboratory tests onto the reference space and 
retrieved the corresponding metabolomics values. All models were 
evaluated by comparing the reconstructed metabolomics against the 
ground-truth Follow-up Visit measurements using metrics such as MSE 
and Pearson correlation. Unlike the longitudinal PULSE framework, 
these static frameworks relied solely on the current visit’s laboratory 
data for reconstruction.

Benchmarking against existing longitudinal clinical modeling 
methods
To position PULSE relative to representative longitudinal clinical mod-
eling paradigms, we additionally benchmarked it on the plasma prot-
eomics generation task using longitudinal clinical history and current 
routine laboratory tests as input. This benchmark was conducted on the 
UK Biobank-PPP cohort, in which each sample consisted of all medical 
history recorded before the current visit, the current-visit routine labo-
ratory measurements and the corresponding measured plasma prot-
eomics profile. Data were split at the patient level into development and 
held-out test sets, such that no individual contributed records to both 
training and testing. The development set was further used for model 
training and validation. For all compared methods, the prediction 
target was identical: generation of the current-visit proteomics vector.
We compared PULSE with three representative paradigms 
from longitudinal clinical data modeling: a Delphi-style diagnosis- 
trajectory model, an adapted Llama 3.1 text-embedding model and 
a standard Transformer encoder. These methods were selected to 
represent three common strategies for modeling longitudinal 
patient information: sequence modeling of diagnostic event tra-
jectories, natural-language-based patient summarization using a 
general-purpose large language model and direct token-based encod-
ing of longitudinal structured clinical data.
For the Llama 3.1 baseline, all precurrent-visit diagnosis records 
were converted into chronological natural-language descriptions and 
current-visit routine laboratory measurements were appended to the 
same patient summary in text form. Laboratory values were described 
using both their measured continuous values and discretized levels. 
These patient summaries were encoded using a frozen Llama 3.1 model, 
and the resulting text embeddings were passed to a multilayer regres-
sion head to predict the current-visit proteomics vector. This baseline 
tests whether general-purpose text embeddings of longitudinal clini-
cal context are sufficient for proteomics generation without explicit 
cross-modal alignment.
For the standard Transformer baseline, longitudinal diagnosis 
history and current routine laboratory data were represented as a struc-
tured token sequence. Diagnosis codes were encoded as age-aware 
event tokens, and current laboratory measurements were discretized 
into feature-specific bins and encoded as laboratory tokens. Token 
embeddings were combined with type embeddings, age embeddings 
and positional embeddings and then processed by a Transformer 
encoder. The final (CLS) representation was passed to a regression head 
to predict the proteomics vector. CLS is the classification token in trans-
former, the aggregated sequence representation used for the predic-
tion head. This model directly uses all available structured inputs but 
does not impose an explicit alignment mechanism across modalities.
For the Delphi-style baseline, we adapted a diagnosis-trajectory 
modeling framework to the same prediction task by using longitudinal 
disease-event history before the current visit to derive a patient trajectory 
representation, which was then passed to a regression head for proteom-
ics prediction. As this class of model is designed primarily for longitudinal 
disease-event trajectories rather than multimodal completion, it could 
not natively incorporate current routine laboratory measurements in 
the same way as PULSE. It therefore served as a diagnosis-history-only 
longitudinal trajectory baseline in this benchmark.
To ensure a fair comparison, all methods were trained and 
evaluated under the same patient-level split and against the same 
current-visit proteomics target. The differences between methods 
therefore reflect their underlying representational assumptions rather 
than differences in the prediction end point. In particular, PULSE 
explicitly models current laboratory data and historical context as 
complementary branches within a shared latent physiological space, 
whereas the comparator methods rely on event-sequence modeling, 
text embedding or direct token-sequence encoding without explicit 
cross-modal alignment.
Benchmark scripts and implementation details for these lon-
gitudinal clinical modeling comparisons are provided in the public 
benchmark repository.
Biological aging trajectories and grouping strategy
Trajectory inference was performed directly on the PULSE latent 
representations. A k-nearest neighbor graph was constructed, fol-
lowed by diffusion pseudotime computation. Using CellRank30,31, a 
pseudotime-informed transition matrix (PseudotimeKernel, time_
key=“dpt_pseudotime”) was generated to derive a vector field of transi-
tion probabilities in latent representations. Streamlines representing 
long-range directional flows were obtained via numerical integration 
of this vector field and subsequently projected onto a UMAP space (n_
neighbors = 30, min_dist = 0.5 and random_state = 42) for visualization.
Trajectory groups were defined to isolate trajectory effects from 
chronological age. Participants were binned into 0.2-year age inter-
vals; within each bin, individuals were ranked by UMAP2 coordinate 
and partitioned into three equal-sized tertiles (upper, middle and 
lower). Assignments were pooled across all age bins to form three 
trajectory groups spanning the full age range. Clinical validation used 
sex-stratified Kaplan–Meier survival analysis (lifelines), with age (years) 
as the time variable and trajectory group as the stratification factor, 
assessing cumulative incidence of major age-related diseases.

Plasma proteomic disease prediction modeling
For each disease, a prediction model was developed using a Light-

healthy at baseline, would develop the specified disease (class 1) or 
remain healthy (class 0) within a 10-year follow-up period; all individu-

were trained on the training set using the true plasma proteomic fea-

on the held-out test set by comparing two input scenarios: using the 
generated plasma proteomic features combined with age and sex and 
using the true plasma proteomic features combined with age and sex.

model trained on the combined inputs of routine laboratory tests, the

Baseline methods of multimodal alignment
For cross-modal alignment pretraining for fundus images and labora-
tory tests, PULSE was pretrained on longitudinal mosaic data from 
the development set, where each visit could contain fundus imaging, 
laboratory tests, or both. Fundus images were first processed through 
a RETFound-pretrained encoder to extract high-level features. These 
fundus-derived features were then aligned with laboratory test meas-
urements and the patient’s past state (derived from previous visits) 
in a joint latent space using the PULSE modality-specific encoder and 
alignment framework.
For systemic disease prediction fine-tuning, after alignment pre-
training, latent state representation of visits with fundus images was 
fine-tuned for disease prediction using only fundus images as input. 
For each disease (ischemic stroke, myocardial infarction, heart fail-
ure and dementia), we constructed a binary classification task for 
5-year incident disease prediction. Visits with pre-existing disease were 
excluded. A visit was labeled as positive if the disease occurred within 
5 years of follow-up and negative otherwise. In single-visit mode, the 
fundus encoder produced a latent representation from the current 
visit only, which was fed to a classification head. In multivisit mode, 
fundus images from the current and all previous visits were sequen-
tially processed, with the final visit representation aggregating the 
longitudinal trajectory before prediction. The model was trained using 
binary cross-entropy loss on the development set and evaluated on the 
held-out test set under both prediction regimes.
For the baseline of systemic disease prediction comparison, the 
RETFound baseline used MAE-pretrained RETFound encoder features 
directly. For single-visit prediction, fundus features from the current 
visit were passed to a classification head. For multivisit prediction, 
an RNN aggregated features from the current and historical fundus 
images before classification. Both PULSE and RETFound models were 
trained and evaluated on identical disease tasks and prediction regimes 
for fair comparison.
For myopia progression prediction fine-tuning, after alignment 
pretraining, the PULSE laboratory test encoder was fine-tuned for 
myopia progression prediction using only laboratory tests as input. The 
task was to predict future AL and SE trajectories over 1–5-year horizons. 
For each visit with available laboratory tests, the encoder processed 
the current visit’s laboratory tests combined with the patient’s past 
state (aggregated from previous visits), producing a latent represen-
tation that was fed to a regression head to predict future refractive 
measurements at 1, 2, 3, 4 and 5 years. The model was trained using 
MSE loss on the development set and evaluated on the held-out test 
set. Performance was assessed using the coefficient of determination 
(R2), MAE and Pearson correlation coefficient between predicted and 
actual values at each future time point.
For baseline comparison, the end-to-end baseline was trained 
solely on laboratory tests without cross-modal pretraining. Laboratory 
tests from the current visit and historical visits were processed through 
a recurrent architecture to aggregate longitudinal information, and 
the resulting representation was passed to a regression head to predict 
future AL and SE trajectories, using the same loss function and evalua-
tion metrics as the PULSE model for fair comparison.
Statistics and reproducibility
Study design and sample size. This study employed a retrospec-
tive observational design using existing longitudinal cohort data. 
No statistical method was used to predetermine sample size. Sample 
sizes were determined by data availability in each cohort. For the 
UK Biobank metabolomics-imputation task, we included ~10,000 
participants with paired baseline and follow-up measurements. The 
UK Biobank-PPP proteomics cohort comprised 50,000 participants. 
The MIMIC-III ICU cohort included 44,265 adult patients, and the 
Wenzhou ICU cohort included 13,816 adult patients. The myopia pre-
diction cohort included 24,605 children contributing 50,043 visits, 
and the systemic disease prediction cohort included 127,731 adults 
contributing 657,103 visits.
Data exclusion. In the ICU readmission analysis, we excluded admis-
sions involving in-hospital death, newborn types or ICU stays shorter 
than 24 h, following standard protocols to focus on adult patients with 
sufficient longitudinal data. For disease prediction tasks, individuals 
with a prevalent diagnosis at baseline were excluded to enable incident 
disease prediction within a 10-year follow-up window. For myopia pro-
gression prediction, visits with pre-existing high myopia were excluded 
to track the development and progression of refractive changes. No 
other data were excluded from the analyses.
Randomization and data splitting. The experiments were not rand-
omized. For model development and evaluation, data were partitioned 
at the patient level (not the visit level) to ensure that all records from 
any given individual appeared in only one split. In the UK Biobank 
metabolomics task, individuals were randomly assigned to a 70% train-
ing set (n = 7,000) and a 30% held-out test set (n = 3,000). The systemic 
disease and myopia cohorts were randomly split at the individual level 
into 70% development and 30% held-out test sets. The ICU cohorts were 
randomly partitioned at the patient level into training, validation and

Blinding. The investigators were not blinded to allocation during

Statistical analyses. Correlation analyses were performed using 
Pearson’s correlation coefficient (r) for linear relationships and Spear-
man’s rank correlation coefficient (ρ) for monotonic relationships, as 
specified in the figure legends. The statistical significance of correla-
tions and group differences was assessed using two-sided t-tests or 
Wilcoxon signed-rank tests, depending on the normality of the data 
distribution. For benchmarking comparisons involving paired predic-
tions (for example, PULSE versus baseline methods), the two-sided 
Wilcoxon signed-rank test was applied across biomarkers or proteins.
95% CIs for model performance metrics (AUROC and AUPRC) and 
regression coefficients were estimated using nonparametric bootstrap 
with 200 resamples, unless otherwise stated. In the main text and fig-
ures, exact P values are reported where P ≥ 0.0001; values below this 
threshold are denoted as P < 0.0001. For most comparative analyses, 
no adjustment for multiple comparisons was applied; exceptions or 
specific adjustments are noted in the relevant figure legends.
Trajectory inference was performed using CellRank (v2)31. We 
embedded unpaired multimodal data from the UK Biobank into a 
unified latent space and computationally inferred aging progression 
trajectories using pseudotemporal ordering. Cumulative incidence 
curves were calculated using the Kaplan–Meier estimator via the life-
linesmodule (Python). Pairwise group differences in survival distribu-
tions were assessed using two-sided log-rank tests.
For disease prediction tasks using LightGBM, models were trained 
on the development set and evaluated on the held-out test set. Class 
imbalance was addressed using class-weighted logistic loss during 
training. Hyperparameters were tuned via threefold cross-validation 
within the training set.

Computational cost
For the UK Biobank metabolomics-generation task, training can be 
completed in less than 1 h on a single modern graphics processing unit 
(GPU) with 24 GB memory. For the UK Biobank proteomics-imputation 
task, training can be completed in less than 3 h on the same hardware. 
In both settings, inference does not require a GPU and takes less than 
1 s per patient on a standard laptop.
